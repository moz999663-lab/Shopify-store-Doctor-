# 🏥 دكتور الأرباح من Shopify - Profit Doctor

أداة ذكية وشاملة لتحليل الأرباح والتشخيص المالي لمتاجر Shopify.

## 📋 نظرة عامة

دكتور الأرباح هو تطبيق Shopify متقدم يساعد أصحاب المتاجر على:

- 📊 فهم أرباحهم الفعلية وليس فقط المبيعات
- 🔍 تشخيص المشاكل المالية تلقائياً
- 💡 الحصول على توصيات قابلة للتنفيذ
- 📈 تتبع الاتجاهات وكشف الشذوذ
- 🎯 اتخاذ قرارات مالية مدفوعة بالبيانات

## 🏗️ البنية المعمارية

### Backend
- **Runtime**: Node.js + TypeScript
- **Framework**: Express.js
- **Database**: PostgreSQL مع Kysely ORM
- **Queue**: Redis + Bull للمهام الخلفية
- **Logging**: Pino

### Frontend
- **Framework**: React 18
- **Language**: TypeScript
- **Routing**: React Router v6

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- PostgreSQL 14+
- Redis 7+
- Docker و Docker Compose (اختياري)

### التثبيت

1. استنساخ المستودع
```bash
git clone https://github.com/moz999663-lab/Shopify-store-Doctor-.git
cd Shopify-store-Doctor-
```

2. بدء قاعدة البيانات والـ Redis
```bash
docker-compose up -d
```

3. تثبيت المتطلبات
```bash
npm install
cd frontend && npm install && cd ..
```

4. إعداد متغيرات البيئة
```bash
cp .env.example .env
```

5. بدء التطوير
```bash
# الخادم الخلفي
npm run dev

# في نافذة أخرى - الواجهة الأمامية
cd frontend && npm start
```
